# MHMW Website Prototype

This is a real static website prototype (HTML + CSS + JavaScript), not an empty scaffold.

## Run locally
Open `index.html` directly, or use VS Code Live Server.

## Deploy to Vercel
Import this folder/repository as a project. No build command is required because this is a static site.

## Files
- index.html — complete page markup
- styles.css — complete responsive design
- script.js — filters, save interactions, reveal motion, mobile menu, waitlist demo
- vercel.json — Vercel static configuration

The image assets are loaded from Unsplash in this prototype, so an internet connection is required for the photography.
